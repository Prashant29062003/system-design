# LLD (Low Level Design)

1. What is LLD?
- Low Level Design

2. Why LLD?
- Scalability
- Manitanability
- Re-usability (i.e. not tightly coupled)

3. What is not LLD?
- HLD (High Level Design)
    - Focusing on (Architecture design)
        - Tech Stack (Java, SpringBoot, TypeScript, etc.) 
        - DB (SQL, NoSQL)
        - Server Scale (how server scale when users are increasing on platform)
        - Cost optimization (like users are increasing/decreasing on platform, how to optimize cost)

4. HLD vs LLD vs DSA
| HLD | LLD | DSA |
| :--- | :----: | ----: |
| Architecture | System Design | Data Structure & Algorithm |
| System Stack | Code structure | Tool |

> NOTE: if DSA is the brain of an application then -> LLD is the skeleton of an application.
